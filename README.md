💰 Expense Tracker

A simple and user-friendly Expense Tracker web application for recording, organizing, and monitoring daily expenses.

🔗 Live Demo: https://etrackerr.vercel.app

✨ Features

- 💰 Add and manage expenses
- 📊 Monitor spending
- 🗂️ Organize expense records
- 📱 Responsive design for mobile and desktop
- 🎨 Clean and user-friendly interface

🛠️ Tech Stack

- ⚛️ React
- 🔷 TypeScript
- ⚡ Vite
- 🎨 CSS
- 🧩 JavaScript
